# Bingie guisettings for 8nime

`guisettings.xml` cannot be hand-authored reliably. It is generated by Kodi when you configure the skin. Follow this procedure on a reference Kodi 21 install to produce build-ready guisettings files.

## Reference install steps

1. Install Kodi 21 Omega (or Nexus 20 minimum).
2. Install repositories and addons from `hosted/addons-*.json`.
3. Set **Bingie** as the active skin.
4. Configure Bingie per the layout in `config/build-manifest.json`.

## Bingie anime menu configuration

### Sidebar shortcuts

Go to **Skin Settings → Configure shortcuts → Edit menu shortcuts**:

| Position | Label | Target |
|----------|-------|--------|
| 1 | Home | Default home hub |
| 2 | Anime Series | Otaku → TV Shows |
| 3 | Anime Movies | Otaku → Movies |
| 4 | Airing Now | Otaku → Airing Anime |
| 5 | Calendar | Otaku → Airing Anime Calendar |
| 6 | Search | Otaku → Search |
| 7 | My List | Trakt Watchlist (via TMDb Bingie Helper) |
| 8 | Settings | Kodi settings |

### Home screen widgets

Go to **Skin Settings → Configure shortcuts → Edit menu shortcuts → Home → Widgets**:

1. **Trending Anime** — TMDb Bingie Helper → Trending TV (genre: Animation/Anime) or Otaku widget
2. **Airing This Season** — Otaku → Airing This Season
3. **Popular Anime** — Otaku → Popular
4. **Top Rated** — Otaku → Voted
5. **Anime Movies** — Otaku → Movies
6. **Continue Watching** — Trakt → Playback Progress

Lock widgets when done: **Skin Settings → Configure shortcuts → Lock widgets in hubs → ON**.

### Trakt and ratings

1. **Skin Settings → Supported addons → TMDb Bingie Helper → Trakt → Authenticate Trakt account**
2. Optional API keys:
   - OMDb: https://www.omdbapi.com/apikey.aspx
   - MDbList: https://mdblist.com/preferences

### Otaku debrid setup (Debrid build only)

1. Open Otaku → **Tools → Accounts**
2. Enable and authorize Real-Debrid at https://real-debrid.com/device

## Export guisettings

After configuration:

1. Open **8nimeWizard → Save Data**
2. Enable **guisettings.xml**
3. Save to a zip, or copy from:
   - Linux: `~/.kodi/userdata/guisettings.xml`
   - Android: `/sdcard/Android/data/org.xbmc.kodi/files/.kodi/userdata/guisettings.xml`
   - Windows: `%APPDATA%\Kodi\userdata\guisettings.xml`

4. Place exported files here:
   - `8nime-free-guisettings.xml`
   - `8nime-debrid-guisettings.xml`

5. Update URLs in `hosted/builds.txt` if hosting path changes.

## Create the build zip

On the reference Kodi install with everything configured:

1. Open **8nimeWizard → Save Data → Create Build**
2. Name: `8nime Free` or `8nime Debrid`
3. Select addons to include per `config/build-manifest.json`
4. Upload the generated zip to `repo/zips/builds/`
